# Test cases: จองคิวตรวจสุขภาพ (Booking)
อ้างอิง: spec.md SPEC-BKG-001 Draft v2

คนออกแบบตารางนี้ AI เขียนโค้ด test ตามตารางด้วยคำสั่ง /testcases
- 1 แถว = 1 test case = 1 test ในโค้ด
- AC 1 ข้อ ควรมีอย่างน้อย 3 แบบ: ทางปกติ / ขอบ / ทางผิด
- ช่อง Then ต้องครบทุกส่วนของ Then ใน AC ส่วนไหนติด Q-xx ให้เขียนว่า "รอ Q-xx" ไว้ในวงเล็บ
- ตรวจด้วย: pytest (หลังบ้าน) / vitest (หน้าจอ) / คน (ลองเองตาม Given When Then)
- สถานะ: ร่าง (AI เสนอ ยังไม่มีใครตรวจ) / ใช้ได้ (ทีมตรวจแล้ว AI เขียนโค้ด test ได้) / รอ Q-xx
- **test ที่มาจากตารางนี้ ห้ามแก้ให้ผ่าน** ถ้าไม่ผ่าน ต้องหาว่าโค้ดผิด หรือ AC ผิด (ถ้า AC ผิด แก้ spec ก่อน)
